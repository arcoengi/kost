КАК ЗАГРУЗИТЬ
В корне репозитория нажмите Add file → Upload files.
Загрузите СОДЕРЖИМОЕ этой папки, сохранив вложенность assets.
Не загружайте папку kost целиком внутрь одноимённого репозитория.
Подтвердите Commit changes и дождитесь успешной публикации GitHub Pages.
Если .gitattributes не загружается: Add file → Create new file,
имя .gitattributes, содержимое одной строкой: *.vcf -text
